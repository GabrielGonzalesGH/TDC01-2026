Pseudocódigo
// Recorre la lista buscando (from==q && symbol==a)
Tdata delta(Automata* A, State q, Symbol a) {
  TransitionNode* curr = A->Delta;
  while (curr != NULL) {
    if (curr->t.from == q && curr->t.symbol == a)
      return curr->t.to;
    curr = curr->next;
  }
  return NULL;
}

Pseudocódigo (Propuesta 2)
// Busca el estado en la lista y luego recorre sus transiciones
Tdata delta(Automata* A, State q, Symbol a) {
  StateNode* curr = A->states;
  while (curr != NULL && curr->name != q)
    curr = curr->next;
  if (curr == NULL) return NULL;
  Transition* t = curr->transitions;
  while (t != NULL && t->symbol != a)
    t = t->next;
  return (t != NULL) ? t->to : NULL;
}

Representación matricial (AFND ejemplo)
La matriz δ: filas = estados (0..2), columnas = símbolos (0:a, 1:b). Cada celda muestra el conjunto destino.

q0 (0) {q1, q2} {q0}

Nota: Las celdas vacías representan el conjunto vacío ({ }). En una implementación de matriz dispersa solo se almacenan las entradas no vacías.

Pseudocódigo (búsqueda lineal en arreglo disperso)
// Busca en el arreglo una entrada que coincida con from y symbol
Tdata delta(Automata* A, int q_idx, int a_idx) {
  for (int i = 0; i < A->deltaSize; i++) {
    if (A->delta[i].from == q_idx && A->delta[i].symbol == a_idx)
      return A->delta[i].to;
  }
  return NULL;  // conjunto vacío
}
Ventaja principal: Si se usara una matriz completa (|Q| x |Σ|), el acceso sería O(1) directamente por índices. En la práctica, se suele implementar como una matriz de punteros.
