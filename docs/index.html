Pseudocódigo
Tdata delta(Automata* A, State q, Symbol a) {
  TransitionNode* curr = A->Delta;
  while (curr != NULL) {
    if (curr->t.from == q && curr->t.symbol == a)
      return curr->t.to;
    curr = curr->next;
  }
  return NULL;
}

Pseudocódigo
Tdata delta(Automata* A, State q, Symbol a) {
  StateNode* curr = A->states;
  while (curr && curr->name != q) curr = curr->next;
  if (!curr) return NULL;
  Transition* t = curr->transitions;
  while (t && t->symbol != a) t = t->next;
  return t ? t->to : NULL;
}

Tdata delta(Automata* A, int q_idx, int a_idx) {
  for (int i = 0; i < A->deltaSize; i++) {
    if (A->delta[i].from == q_idx && A->delta[i].symbol == a_idx)
      return A->delta[i].to;
  }

}

📦 Propuesta 5 — Estados Compuestos para Determinización

Idea general
Durante la determinización de un AFND a un AFD, cada estado del AFD es un subconjunto de estados del AFND. Esta propuesta se enfoca en representar explícitamente esos estados compuestos y las transiciones entre ellos, facilitando la construcción del autómata determinista resultante.
Representación gráfica
        a
+----------------+
|    {q0,q1}     |
+----------------+
          |
          | b
          v
+----------------+
|    {q0,q2}     |
+----------------+
          |
          | a
          v
+----------------+
|   {q0,q1,q2}   |
+----------------+
Cada estado compuesto (subconjunto) se convierte en un nodo del AFD.

El AFD construido explícitamente a partir de la construcción por subconjuntos.
Construcción paso a paso (usando el AFND ejemplo)
  1. Estado inicial: {q0}
  2. Desde {q0}:
      - Con 'a' → {q1,q2}
      - Con 'b' → {q0}
  3. Desde {q1,q2}:
      - Con 'a' → δ(q1,a) ∪ δ(q2,a) = {q2} ∪ {} = {q2}
      - Con 'b' → δ(q1,b) ∪ δ(q2,b) = {} ∪ {q0} = {q0}
  4. Desde {q2}:
      - Con 'a' → {} (vacío)
      - Con 'b' → {q0}

Los subconjuntos alcanzables son: {q0}, {q1,q2}, {q2}. El estado {q2} es final porque contiene q2 (estado final original).

[{q2}, a, {}], [{q2}, b, {q0}]
Ventajas
  • ✅ Ideal para implementar determinización (construcción por subconjuntos).
  • ✅ Muy alineado con la teoría formal de autómatas.
  • ✅ Facilita la conversión automática de AFND a AFD.
  • ✅ Reutiliza los TADs SET para representar subconjuntos.
Desventajas
  • ❌ Requiere estructuras adicionales para manejar estados compuestos.
  • ❌ La comparación de subconjuntos puede ser costosa si no se usan representaciones canónicas (como cadenas ordenadas).
