📐 A — Simetría y recursión envolvente

A.1   L = { w ∈ {a,b}* | w = wR } (palíndromos)

GLC: S → aSa | bSb | a | b | ε

Derivación izq. para "aba": S ⇒ aSa ⇒ a b a

Derivación der.: S ⇒ aSa ⇒ a b a

Árbol: (dibujo textual o imagen)

5 cadenas: ε, a, b, aa, bb, aba, bab, abba ...

Ambigüedad: No, es única (cada palíndromo tiene una única derivación).

A.2   L = { w ∈ {(,)}* | paréntesis balanceados }

Derivaciones: S ⇒ (S) ⇒ (SS) ⇒ (()()) ...

Árboles: ...

Ambigüedad: Sí, por ejemplo "()()" tiene dos árboles (SS asociado a izquierda/derecha).

🔢 B — Restricciones numéricas

B.1   na(w) = 2·nb(w)

S → aS aS b | b aS aS | ε ??? (estrategia)

O bien: S → aS aS bS | ε con control ...

B.2   an bm | n = 2m+1

S → aaSb | aab (base m=0 → aab?) Mejor: S → aaSb | a

Para m=0 → n=1 → "a". Correcto: S → aaSb | a

B.3   n ≤ m+3

Descomposición: S → aS | aT | ε? Mejor: generar cualquier número de b's primero? La condición es sobre n y m. Se puede hacer por casos: m ≥ n-3.

B.4   2n ≤ m ≤ 3n

S → a S b b | a S b b b | ε (genera cada a acompañado de 2 o 3 b's).

🧩 C — Descomposición o combinación de casos

C.1   an bm | n ≠ 2m

Unión de dos lenguajes: n < 2m ∪ n > 2m.

S → S1 | S2 ; S1 genera anbm con n<2m ; S2 con n>2m.

C.2   na(w) ≠ nb(w)

S → A | B ; A genera cadenas con más a's que b's ; B más b's que a's.

A → aA | aAb | ε? (tener cuidado).
